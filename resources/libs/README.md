Coloca aquí las librerías no oficiales que quieras que Azure Launcher copie automáticamente a la carpeta de Minecraft.

Ejemplo de estructura para OptiFine:

resources/libs/optifine/launchwrapper-of/2.3/launchwrapper-of-2.3.jar
resources/libs/com/optifine/OptiFine/1.20.1_HD_U_I8/OptiFine-1.20.1_HD_U_I8.jar

Cuando se inicia un juego, el launcher copia automáticamente los archivos de esta carpeta a:

.minecraft/libraries/

De esta forma tu launcher puede evitar dependencias externas en servidores de Mojang para librerías no oficiales como OptiFine.
